# ClaudeStatusBar

macOS menu bar uygulaması. Claude Code CLI session durumunu tek renkli nokta
ile gösterir: sarı = çalışıyor, yeşil = bitti, kırmızı = soru soruyor. Detay
için `README.md` ve `DEVLOG.md`.
